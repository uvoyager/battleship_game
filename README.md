# Battleship

A Python implementation of the classic Battleship game with a unique twist: players can freely combine ship segments to create custom ship shapes. Unlike the traditional game, there are no predefined ship layouts—design your fleet however you like.

## Features
- Custom ship creation with no shape restrictions
- Local multiplayer gameplay
- Graphical interface built with Tkinter and Pygame
- Object-oriented architecture

## Technologies
- Python Standard Library
- Tkinter
- Pygame
